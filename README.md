# prt2pdf

HWAS 软件 `.prt` 作业试卷 → A4 PDF 转换工具。

解析 `.prt` 二进制格式中的题目图片，按题型（选择题/填空题/解答题）分章节智能排版，生成适合打印的 A4 PDF。

## 功能

- 📄 **A4 排版** — 150 DPI，自动缩放题目图片至适合宽度，50px 页边距
- 🏷️ **章节标题** — 自动渲染"选择题""填空题""解答题"标题，题型分布从文件头动态读取
- 📐 **智能间距** — 不同题型使用不同间距：选择紧凑、填空适中、解答题留足写过程空间
- 🧱 **块级排版** — 每道题 = 图片 + 题后空白 = 一个不可分割的块，不会被截断在页尾
- 📏 **间距压缩** — 块在本页放不下时自动压缩空白区域（不低于原间距 40%），避免大片留白
- 🔄 **动态适配** — 题型数量从文件头 `[cntA, cntB, cntC]` 读取，不同试卷自动适配

## 依赖

- Python 3.7+
- [Pillow](https://python-pillow.org/) (PIL)

```bash
pip install Pillow
```

## 用法

```bash
python prt2pdf.py <文件.prt>
```

输出文件为同目录下的同名 `.pdf` 文件。

```bash
# 示例
python prt2pdf.py practice1.prt
# → practice1.pdf
```

## 可调参数

编辑 `prt2pdf.py` 顶部的常量即可调整排版效果：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `GAP_CHOICE` | 60px | 选择题之间间距 (~10mm) |
| `GAP_FILL` | 60px | 填空题之间间距 (~10mm) |
| `GAP_COMP` | 550px | 解答题之间间距 (~93mm，留写过程空间) |
| `GAP_SECTION` | 100px | 章节标题上方留白 (~17mm) |
| `GAP_AFTER_TITLE` | 20px | 标题与首题间距 (~3mm) |
| `MIN_GAP_RATIO` | 0.4 | 间距压缩底线（不低于原间距 40%） |
| `TITLE_FONT_SIZE` | 30 | 章节标题字号 |
| `A4_W / A4_H` | 1240×1754 | A4 画布尺寸（150 DPI） |
| `MARGIN` | 50px | 页边距 |

## .prt 文件格式

```
头部 63 字节:
  [魔数 qyhisme 7B]
  [零填 12B]
  [版本 1B]
  [选择数 cntA 1B]    ← 动态，不同试卷不同
  [填空数 cntB 1B]
  [解答数 cntC 1B]
  [每题答案数 19B]    ← 做题软件用，PDF 排版忽略
  [首图尺寸 ASCII 5B]
  [零填 16B]

随后: 顺序排列的 PNG 图片（前 cntA 张选择 → 中 cntB 张填空 → 后 cntC 张解答）
每张 PNG 之间: 20 字节间隔块（含下一张图尺寸）

尾部: UTF-8 中文试卷标题 + 二进制元数据
```
